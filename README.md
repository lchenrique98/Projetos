### NasaApi

Aplicação web desenvolvida em React para explorar conteúdos e informações disponibilizados pelas APIs da NASA.

O projeto permite consultar a **Imagem Astronômica do Dia (APOD)**, visualizar informações sobre **asteroides próximos da Terra (NeoWs)** e pesquisar imagens no acervo da NASA.

**Tecnologias:**
- React
- JavaScript
- React Router
- Vite
- HTML
- CSS
- NASA APIs
