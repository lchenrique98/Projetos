# Projetos da Faculdade

Repositório destinado a projetos e trabalhos desenvolvidos durante minha graduação em **Análise e Desenvolvimento de Sistemas**.

## Projetos

### HelpDesk TI
Sistema de ordens de serviço para suporte técnico, com perfis de solicitante e técnico.
O solicitante abre chamados e acompanha o andamento; o técnico usa um painel de atendimento para assumir chamados, atualizar o status e conversar com o solicitante pelos comentários.
Senhas criptografadas com BCrypt e acesso ao banco protegido com PreparedStatement.

**Tecnologias:**
- Java 21
- Servlets e JSP (Jakarta EE)
- MySQL
- Tomcat 11
- Maven
- HTML e CSS

📁 Código na pasta [`helpdesk`](./helpdesk)

### Floricultura
Sistema de gestão para uma floricultura.
Permite cadastrar produtos com foto e fornecedor, controlar o estoque com entradas e baixas, registrar vendas com vários itens, gerenciar encomendas com data de entrega e status, e manter o cadastro de clientes (com busca de endereço pelo CEP) e fornecedores.

**Tecnologias:**
- Python
- Django 5.2
- MySQL
- HTML
- CSS
- JavaScript

📁 Código na pasta [`floricultura`](./floricultura)

### NasaApi
Aplicação web desenvolvida em React para explorar conteúdos e informações disponibilizadas pelas APIs da NASA.
O projeto permite consultar a Imagem Astronômica do Dia (APOD), visualizar informações sobre asteroides próximos da Terra (NeoWs) e pesquisar imagens no acervo da NASA.

**Tecnologias:**
- React
- JavaScript
- React Router
- Vite
- HTML
- CSS
- APIs da NASA
